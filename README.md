# Yifang (Mark) Chen (陈义方) — personal website

This repository contains my personal academic website, built with the [al-folio](https://github.com/alshedivat/al-folio) Jekyll theme and deployed with GitHub Pages.

The site's content lives primarily in:

- `_pages/about.md`
- `_bibliography/papers.bib`
- `_data/socials.yml`
- `_news/`

GitHub Actions builds and deploys the site after changes are merged into `main`.
